# SNOW GUIDE — v27

Snow Manファン向けの非公式音楽応援ガイド。`index.html`をブラウザで開くだけで閲覧できます。外部のJavaScript・画像・フォントを使わない単一HTMLです。GitHub Pagesに公開する場合はこのHTMLをルートに配置してください。

## 今回の整理

- 7章を順番に読める構成に統一し、ナビと章番号を一致させました。
- 公式リンク集にあるストリーミング先6社だけを本文で個別比較。ダウンロード購入先3社は別枠に分離。
- 公式リンク集外のサービスも、サービス内の再生実績や各チャート対象になり得ることを明記。
- 繰り返していた「減算対策」「数字への反映」の説明を整理し、公式ルールと通説を区別。
- リスパとStationheadを対等に説明。ファンによるStationhead配信を記載。
- チャートは「何の順位／対象／やること／期間」で統一。
- 謝辞は固有のファンダム名を掲載しない版を保持。

## 更新の目安

集計条件・サービス料金・接続環境・アプリUIは変わります。適宜公式リンクを確認し、上半期と年間ランキング発表時に実績部分を見直してください。個別の新曲名は置いていないので新譜ごとの変更は原則不要です。

## 注意

推奨の聴き方は有効再生を保証するものではありません。各サービスの利用規約を守り、不自然な再生操作を推奨しない構成です。
